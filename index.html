下载与安装

国内直连 GitHub 可能很慢或超时。在链接前加加速前缀通常就行，例如 https://ghfast.top/ + 原链接。raw 那一条走的是不同域名，很多时候比 Release 更快。

装不上？Android 需要在设置里允许「安装未知来源应用」；已装旧版会提示签名冲突， 先卸载旧版再装。

校验安装包：用 MT 管理器或 Termux 算 sha256，和上面的值逐字对比。 sha256sum HGhub-1.2.19.apk
